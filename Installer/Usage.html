Quickhand POS 授权工具

LicenseKeyGenerator · 厂商／内部操作人员使用

本安装包只安装授权工具，不安装 POS、数据库或客户数据。已有签名密钥可以继续使用，不要因为升级工具而重新创建密钥。

1. 安装和打开

  1. 在实际使用授权工具的 Windows 用户下运行安装包，按提示完成安装。
  2. 从桌面或开始菜单打开 LicenseKeyGenerator。
  3. 程序需要 .NET Framework 4.8 或更新的兼容版本；缺少时安装程序会提示。

2. 首次设置

  1. 打开 First-time setup，确认顶部的 License data folder。Open data folder 可打开目录；Choose data folder... 可选另一份资料目录。
  2. 输入密钥密码。已有密钥：点击 Use existing key...，选择原来的 .pfx。工具将密钥和签发历史复制到分类目录，原文件保留；不会用旧历史覆盖较新记录。
  3. 没有密钥：填写至少 16 字符的密码及确认密码，点击 Create new key...。私钥自动放入 01_SigningKeys，公钥放入 02_PublicKeys。已有客户的密钥请继续沿用。
  4. 只有首次使用新密钥时，才需要由开发人员选择 POS 源码目录，点击 Configure POS key 并重新构建、部署 POS。日常签发无需 POS 源码和 Inno Setup。小屏幕可向下滚动查看构建按钮。

3. 日常生成授权

  1. 客户在 POS 的授权页面点击 Export request，将请求 JSON 发给操作人员。
  2. 打开 Generate license，点击 Load request...。申请自动归档到 03_CustomerRequests。
  3. 新客户自动生成可修改的 CUS-… 客户编号、STR-… 门店编号。同一客户新增门店时沿用原客户编号；续期优先读取历史中的原编号，找不到时请填写原编号。随机编号支持离线多机生成，重复概率极低；手工修改时仍须核对。
  4. 核对购买功能，输入密钥密码，勾选已核对购买权益，点击 Generate license。授权自动存入 04_IssuedLicenses → Customer-客户编号 → Store-门店编号；若在另存为中选择其他位置，会额外导出一份。
  5. 仅把生成的 .qhlic 文件交给客户。客户通过 Import license 导入。

4. 旧客户

Legacy... 保留旧授权生成入口。license.key 按日期归档到 04_IssuedLicenses/Legacy 的独立目录，另存到其他位置时也保留归档。开始菜单中的 Legacy machine code 用于显示旧版机器码。

5. 资料保存、换电脑与升级

开发版默认使用工程目录旁的 QuickhandLicenseKeys；安装版首次默认使用“文档”中的同名目录。选择过资料位置后会记住它。路径提示文件在 %LocalAppData%\QuickhandPOS\LicenseIssuer，实际配置在 06_Settings，不包含密码。

  • 01_SigningKeys：私钥；02_PublicKeys：公钥。
  • 03_CustomerRequests：申请；04_IssuedLicenses：授权。
  • 05_IssuanceRecords：签发历史，续期不可缺少。
  • 06_Settings：路径配置；07_PrivateNotes：人工私密记录；08_Backups：人工备份，程序不会自动做异地备份。

换电脑前关闭工具，复制整个资料目录。在新电脑点击 Choose data folder... 选择复制好的目录，再用 Use existing key... 选择目录内的 PFX，更新旧电脑路径。请把密码另外妥善保管；程序不保存密码。同一把密钥请使用完整、最新的一份签发历史，避免多台电脑各用独立副本同时签发。

关闭两个工具再运行新版安装包；升级及卸载保留外部资料。此版本支持安装包覆盖升级，未提供联网自动更新。

不要将 PFX、密钥密码、完整签发历史或这个厂商工具发给客户。授权 PFX 密钥与 POS 升级包的签名密钥是两套不同的用途。

常见问题

  • 客户请求不是签名密钥：请求 JSON 用 Load request，PFX 用 Use existing key。
  • 客户提示未知公钥：先更新客户 POS，使其信任该密钥；不能靠重新安装厂商工具解决。
  • Build installer 找不到 POS 源码：该按钮用于构建 POS 安装包；请另行选择 POS 源码。日常生成授权无需使用它。
