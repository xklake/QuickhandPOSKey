Quickhand POS 授权工具

LicenseKeyGenerator · 厂商／内部操作人员使用

本安装包只安装授权工具，不安装 POS、数据库或客户数据。已有签名密钥可以继续使用，不要因为升级工具而重新创建密钥。

1. 安装和打开

  1. 在实际使用授权工具的 Windows 用户下运行安装包，按提示完成安装。
  2. 从桌面或开始菜单打开 LicenseKeyGenerator。
  3. 程序需要 .NET Framework 4.8 或更新的兼容版本；缺少时安装程序会提示。

2. 首次设置

  1. 打开 First-time setup，输入密钥密码。
  2. 已有密钥：点击 Use existing key...，选择原来的 .pfx。已有路径配置通常自动读取。
  3. 没有密钥：填写至少 16 字符的密码及确认密码，点击 Create new key...。保存在源码仓库和程序安装目录之外，并备份 PFX、密码及同目录的 license-issuance.jsonl。
  4. 只有首次使用新密钥时，才需要由开发人员选择 POS 源码目录，点击 Configure POS key 并重新构建、部署 POS。日常签发无需 POS 源码和 Inno Setup。

3. 日常生成授权

  1. 客户在 POS 的授权页面点击 Export request，将请求 JSON 发给操作人员。
  2. 打开 Generate license，点击 Load request...。
  3. 核对 Customer ID、Store ID 和购买功能；输入密钥密码。
  4. 勾选已核对购买权益，点击 Generate license，选择文件保存位置。
  5. 仅把生成的 .qhlic 文件交给客户。客户通过 Import license 导入。

4. 旧客户

Legacy... 保留旧授权生成入口。生成文件时会弹出“另存为”；选择客户资料目录，保存 license.key。开始菜单中的 Legacy machine code 用于显示旧版机器码。

5. 更新与卸载

先关闭两个工具，再运行新版安装包。安装范围固定为当前 Windows 用户，默认沿用原安装目录。安装包只替换程序文件，不重建密钥或删除签发记录。

设置保存在 %LocalAppData%\QuickhandPOS\LicenseIssuer。卸载保留此目录及外部保存的密钥、授权、签发记录；请自行妥善备份。此版本支持安装包覆盖升级，未提供联网自动更新。

不要将 PFX、密钥密码、完整签发历史或这个厂商工具发给客户。授权 PFX 密钥与 POS 升级包的签名密钥是两套不同的用途。

常见问题

  • 客户请求不是签名密钥：请求 JSON 用 Load request，PFX 用 Use existing key。
  • 客户提示未知公钥：先更新客户 POS，使其信任该密钥；不能靠重新安装厂商工具解决。
  • Build installer 找不到 POS 源码：该按钮用于构建 POS 安装包；请另行选择 POS 源码。日常生成授权无需使用它。
